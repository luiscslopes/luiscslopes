### 🚀 PROJETO EM DESTAQUE

### 💰 Projeto 12X8

Sistema de controle financeiro desenvolvido em Python, criado para praticar programação e transformar os conhecimentos estudados em um projeto completo. 

### 🌟 Principais recursos:

* 📑 **Cadastro de receitas e despesas**: Registro simplificado de fluxos financeiros.
* ✏️ **Edição e exclusão**: Controle total sobre as movimentações cadastradas.
* 📊 **Resumo financeiro**: Visualização clara dos saldos e totais.
* 💾 **Persistência de dados em JSON**: Armazenamento seguro que mantém as informações salvas.
* 🖥️ **Interface gráfica com Tkinter**: Tela visual intuitiva e amigável para o usuário.
* ⚠️ **Validações de dados**: Sistema que evita erros de digitação e entradas inválidas.
* 🛠️ **Código limpo**: Organização e refatoração estruturadas seguindo boas práticas.
* 🗃️ **Versionamento**: Projeto totalmente gerenciado com Git e GitHub.
