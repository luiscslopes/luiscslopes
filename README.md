### 🚀 PROJETO EM DESTAQUE

### 💰 [Projeto 12X8](https://github.com/luiscslopes/projeto-12x8)

Sistema de controle financeiro desenvolvido em Python, criado para praticar programação e transformar os conhecimentos adquiridos em um projeto completo. 

### 🌟 Principais recursos:

* 📑 **Cadastro de receitas e despesas**: Registro de movimentações financeiras.
* ✏️ **Edição e exclusão**: Gerenciamento das movimentações cadastradas.
* 📊 **Resumo financeiro**: Visualização dos principais totais e do saldo.
* 💾 **Persistência de dados em JSON**: Armazenamento dos dados entre as execuções.
* 🖥️ **Interface gráfica com Tkinter**: Interface visual para interação com o sistema.
* ⚠️ **Validações de dados**: Tratamento de entradas inválidas.
* 🛠️ **Organização e refatoração**: Código estruturado e continuamente aprimorado.
* 🗃️ **Versionamento com Git e GitHub**: Histórico e acompanhamento da evolução do projeto.
